# Repository Guide

## Purpose

This repository is a curated list of useful AI Agent Skills and related workflows.

- `README.md` is the default English entry.
- `README.zh-CN.md` is the Simplified Chinese entry.

## Maintaining the List

- When adding, removing, moving, or editing an entry, keep both README files aligned in project set, category structure, order, and language-switch links.
- Format each entry as a project link followed by one accurate, concise sentence.
- Keep descriptions natural in each language.
- Keep the list concise and easy to scan, with a consistent entry format and purpose-based categories.

## Checks

- Review Markdown structure, links, bilingual alignment, and the final diff.
- Run `git diff --check` after changes.
- Do not commit or push without explicit user authorization.

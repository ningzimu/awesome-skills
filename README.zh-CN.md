## 不想每次自己挑 Skill？

把下面这句话发给你的 AI：

> 请安装这个 Skill：https://github.com/ningzimu/awesome-skills/tree/main/skills/awesome-skills

装好以后，遇到新任务时，它会先看这份清单，再自己判断有没有合适的 Skill 可以装和使用。你不用每次翻列表，也不用自己比较哪个更合适。

## Skill 生态

## 编码与开发

- **[multica-ai/andrej-karpathy-skills](https://github.com/multica-ai/andrej-karpathy-skills)** — 基于 Andrej Karpathy 对 LLM 编程常见失误的观察，提供可复用的编码行为准则，核心包括编码前思考、保持简单、精准修改和目标驱动执行。

- **[tanweai/pua](https://github.com/tanweai/pua)** — 结合持续推进提示、系统化调试和主动执行的高能动性编码工作流。

- **[UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)** — 用于选择 UI 风格、配色、字体与组件模式的可检索设计知识库。

- **[emilkowalski/skills](https://github.com/emilkowalski/skills/tree/main/skills/emil-design-eng)** — 面向 UI 打磨、组件质感、动效取舍和交互细节的设计工程指南。

- **[greensock/gsap-skills](https://github.com/greensock/gsap-skills)** — GSAP 官方的 AI 编码 Agent Skills，覆盖常见动画模式，以及 ScrollTrigger、MotionPath、Flip 等插件。

- **[pbakaus/impeccable](https://github.com/pbakaus/impeccable)** — 面向 AI 编码 Agent 的设计工作流，覆盖 UI 规划、设计评审、质量审查和浏览器实时迭代。

- **[Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill)** — 一组前端设计 Skills，可用于确定视觉方向、重设计已有界面，以及把视觉参考转化为代码。

## 研究与情报

## 视频与动态内容

- **[browser-use/video-use](https://github.com/browser-use/video-use)** — 让编码 Agent 把原始素材剪成成片，支持剪辑、字幕、去口头禅和调色。

- **[geekjourneyx/hyperframes-motion-director](https://github.com/geekjourneyx/hyperframes-motion-director)** — 将文章、产品、网站和 README 转化为中文优先的动态视频制作流程。

- **[dexhunter/seedance2-skill](https://github.com/dexhunter/seedance2-skill)** — 为 Seedance 2.0 视频生成创建结构化提示词。

- **[ningzimu/xiaohu-video-translate](https://github.com/ningzimu/xiaohu-video-translate)** — 在本地完成下载、转写、翻译、润色和字幕烧录，将外语视频制作为中文字幕视频。

- **[MapleShaw/yt-dlp-downloader-skill](https://github.com/MapleShaw/yt-dlp-downloader-skill)** — 通过基于 `yt-dlp` 的 Agent 工作流下载视频。

## PPT 与演示文稿

- **[chuspeeism/dashi-ppt-skill](https://github.com/chuspeeism/dashi-ppt-skill)** — 基于多套视觉主题生成可在浏览器编辑的演示文稿，并可导出为 HTML、PDF 或可编辑 PPTX。

- **[ningzimu/codex-ppt-skill](https://github.com/ningzimu/codex-ppt-skill)** — 面向 Codex 的图像型 PPT 生成 Skill，用于从内容策划到幻灯片视觉生成的完整流程。

- **[ningzimu/image-to-editable-ppt-skill](https://github.com/ningzimu/image-to-editable-ppt-skill)** — 将幻灯片图片或 PDF 重建为可编辑 PPT，适合已有演示稿的还原与二次修改。

- **[ningzimu/awesome-ai-ppt](https://github.com/ningzimu/awesome-ai-ppt)** — AI PPT 与演示文稿自动化相关的精选资源合集，收录工具、项目与实践资料。

- **[op7418/guizang-ppt-skill](https://github.com/op7418/guizang-ppt-skill)** — 生成精致的单文件 HTML 演示文稿、PPT 配图和社交媒体封面。

- **[helloianneo/ian-handdrawn-ppt](https://github.com/helloianneo/ian-handdrawn-ppt)** — 以 PNG 形式生成中文手绘技术演示文稿整页视觉。
